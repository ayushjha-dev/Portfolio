WIRIDS

Autonomous web defacement detection and incident response system.

Overview

WIRIDS is designed as an autonomous sentry for web properties. It actively crawls and monitors site structures, capturing screenshots and logs to analyze layout differences and alert administrators immediately.

The Challenge

Standard file-integrity checkers miss database-driven defacements, and running constant checks can load servers. WIRIDS resolves this by combining visual comparison (computer vision) with AI-driven content classification.

"WIRIDS acts as an automated security analyst. It detects visual and code changes, attributes them to threat groups, and responds to mitigate defacement impacts."

Technical Architecture

The system combines headless browser operations, computer vision diffing, and LLM classification:

  • Crawler (Playwright): Headless crawler that scans targets, captures dynamic page screenshots, and dumps HTML DOM configurations.
  • Visual Diff (OpenCV): Runs image matching to identify changes in structure, layouts, or static banners.
  • AI Classifier (Google Gemini): If a change is detected, WIRIDS sends screenshots and HTML to Gemini to attribute the attack style and payload to known threat actor patterns.
  • Alerts & Signatures: Dispatches Discord/Slack webhooks containing cryptographic hashes of compromised files for secure evidence storage.

Implementation Highlight

This Python callback shows how Playwright captures target snapshots and uses OpenCV structural similarity matching to evaluate layout integrity:

async def capture_and_verify(page, baseline_img_path, current_img_path):
    # 1. Capture dynamic target page snapshot
    await page.screenshot(path=current_img_path, full_page=True)

    # 2. Match structural similarity index (SSIM)
    baseline = cv2.imread(baseline_img_path, cv2.IMREAD_GRAYSCALE)
    current = cv2.imread(current_img_path, cv2.IMREAD_GRAYSCALE)
    
    score, diff = structural_similarity(baseline, current, full=True)
    if score < 0.95:
        # Defacement indicator triggered
        await trigger_incident_response(diff)
