Quietude

Minimalist, ambient writing space built for cognitive focus.

Overview

Quietude combines procedural audio synthesis with a distraction-free writing environment to help developers and writers optimize flow state sessions.

The Challenge

Most modern text editors and focus spaces are cluttered with sidebars, sync warnings, and configuration tabs that break cognitive concentration. The objective was to design a clean editing interface that runs client-side and helps users maintain focus.

"Clean interfaces encourage deep focus. By stripping away standard configuration menus, we created an editor that gets out of the user's way."

Technical Architecture

Quietude is built as a single-page web application leveraging:

  • Web Audio Engine: Generates real-time soundscapes (white/brown noise, binaural beats) procedurally, avoiding large static audio files.
  • Focus DOM state: Monitored via writing state listeners, hiding controls and parameters as soon as typing begins.
  • Client Storage: Keeps writing logs safe locally in the browser's `localStorage` to safeguard files without remote logins.

Implementation Highlight

This TypeScript snippet shows how a Web Audio API context creates and connects a procedural brown noise generator node:

TypeScript 
export function createBrownNoiseNode(ctx: AudioContext): AudioNode {
    const bufferSize = 2 * ctx.sampleRate;
    const noiseBuffer = ctx.createBuffer(1, bufferSize, ctx.sampleRate);
    const output = noiseBuffer.getChannelData(0);
    
    let lastOut = 0.0;
    for (let i = 0; i < bufferSize; i++) {
        const white = Math.random() * 2 - 1;
        // Apply brown noise filter algorithm
        output[i] = (lastOut + (0.02 * white)) / 1.02;
        lastOut = output[i];
        output[i] *= 3.5; // Compensate loss
    }
    
    const noiseNode = ctx.createBufferSource();
    noiseNode.buffer = noiseBuffer;
    noiseNode.loop = true;
    return noiseNode;
}
