Pratyaksh.ai

AI-powered real-time surveillance and anomaly detection system.

Overview

Pratyaksh.ai is an intelligent surveillance framework that processes live video streams to identify anomalies, detect threats, and trigger emergency responses.

The Challenge

Traditional motion-based alarm systems trigger excessive false alarms (animals, weather shadows). Pratyaksh.ai filters out the background noise using specialized convolutional filters to isolate human posture, identify weapon patterns, and detect perimeter breaches.

"Evident detection. Pratyaksh.ai analyzes security feeds frame-by-frame, applying neural classifiers to ensure true threat events are flagged immediately."

Technical Architecture

The project architecture consists of three processing layers:

  • Ingress Pipeline (OpenCV): Decodes RTSP security camera streams, downsamples frames, and extracts regions of interest (ROI) to save memory.
  • Classification Core (PyTorch): A customized convolutional neural network optimized to identify breach actions, unauthorized entries, and object threats.
  • Alert Broker (FastAPI): Broadcasts critical alerts to monitoring dashboards via WebSockets, ensuring minimal notification lag.

import torch
import cv2

def analyze_frame(frame, model, device, threshold=0.85):
    # 1. Resize and normalize frame
    resized = cv2.resize(frame, (224, 224))
    tensor = torch.from_numpy(resized).permute(2, 0, 1).float().unsqueeze(0).to(device)
    tensor /= 255.0
    
    # 2. Evaluate posture threat probabilities
    with torch.no_grad():
        outputs = model(tensor)
        probabilities = torch.sigmoid(outputs)
        
    threat_score = probabilities[0][1].item() # Anomaly class score
    if threat_score > threshold:
        trigger_dashboard_alert(threat_score)
