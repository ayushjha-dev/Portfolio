VibeMeet

A browser-based video conferencing platform built on WebRTC and LiveKit.

Overview

VibeMeet is a secure, browser-native video conferencing application that simplifies meeting creation and participation. Using WebRTC protocols mediated by LiveKit SFU (Selective Forwarding Unit), it connects multiple users concurrently with low latency and clean media quality.

Key Capabilities

  • Room System: Dynamic room creation using short, shareable verification tokens and access keys.
  • Media Management: Live mute selectors, input device switching (cameras/microphones), and screen sharing controls.
  • Dynamic Layout Grid: Automatically re-adjusts feed frames depending on the active speakers and grid size to prioritize active participation.
"Real-time video requires strict resource management. Active tracks must be mounted, unmounted, and scaled to maintain connection stability even in low-bandwidth scenarios."

Technical Architecture

VibeMeet separates media routing from app states:

  • LiveKit Server: Serves as the SFU backend, handling active video and audio tracks optimization.
  • React + Vite Client: Provides instant hot module updates during development, fast client loading, and handles states like track visibility.
  • Tailwind CSS: Controls grid transitions, responsive containers, and media controls overlays.
