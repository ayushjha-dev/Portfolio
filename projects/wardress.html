Wardress

Self-hosted website defacement detection and automated response orchestration.

Overview

Wardress is a production-grade, self-hosted security tool built to protect website integrity. It captures and freezes a trusted baseline of your target website — DOM structure, network references, visual layout, and textual semantics — and continuously monitors the site for malicious defacements, script injections, metadata tampering, and domain hijacking.

Nine distinct detection layers, dynamic risk fusion, multi-channel alerting, and guarded remediation — all deployed via Docker Compose on infrastructure you control.

The Problem

Traditional page monitors are simplistic and produce too many false positives. Rotating ads, timestamps, and cache-busting references trigger unnecessary alerts. Meanwhile, sophisticated attacks like script injections, metadata tampering, and subtle DOM modifications can slip through undetected.

Security teams need a solution that distinguishes between benign content churn and genuine security threats — without relying on third-party cloud services that see your sensitive monitoring data.

"Unlike simple page monitors, Wardress aggregates results from 9 independent detection layers into a single fused risk score. Rule-based minimum-risk floors keep high-specificity attack evidence from being drowned out by ordinary site churn."

Technical Architecture

Wardress employs a sophisticated multi-layer detection system that analyzes various aspects of website integrity:

  • DOM Structure Analysis: Monitors HTML element hierarchy and detects unauthorized structural modifications.
  • Network Reference Tracking: Identifies new external script domains and unexpected resource loading patterns.
  • Visual Layout Detection: Uses computer vision to detect visual defacements and layout anomalies.
  • Textual Semantics: Analyzes content changes and identifies defacement signatures.
  • Script Injection Detection: Monitors for new or modified JavaScript execution.
  • Metadata Tampering: Tracks changes to meta tags, titles, and SEO elements.
  • Domain Hijacking Detection: Monitors DNS records and domain ownership indicators.
  • Crawler Cloaking Detection: Identifies attempts to serve different content to bots versus users.
  • AI-Assisted Classification: Optional AI model integration for ambiguous incident analysis.

Risk Fusion System

The core innovation in Wardress is its dynamic risk fusion engine. Instead of binary pass/fail checks, each detection layer produces a normalized risk score. These scores are aggregated with intelligent weighting:

  • Minimum-Risk Floors: High-specificity indicators (new external scripts, known defacement patterns) set a floor that prevents dilution by low-risk changes.
  • Adaptive Scanning: Subtler changes shorten scan intervals and can trigger AI review for operator assessment.
  • Tunable Thresholds: Per-site flag thresholds allow customization based on site characteristics and risk tolerance.
  • Historical Context: Risk scoring considers change frequency patterns to distinguish attacks from legitimate updates.

Self-Hosted & Privacy-First

Wardress runs entirely on your infrastructure. Dashboard imagery is bundled same-origin by default: site avatars are local letter tiles, provider logos ship with the app, and the browser makes no third-party image-CDN requests.

An opt-in server-side favicon resolver (Settings → Site favicons, off by default) lets your own server fetch each monitored site's icon once and cache it locally. No data leaves your control unless you explicitly configure external alerting channels.

Deployment & Integration

Wardress deploys via Docker Compose for simplified orchestration. The system includes:

  • Web Dashboard: Real-time monitoring interface with historical incident tracking.
  • Multi-Channel Alerting: Webhook integrations for Slack, Discord, PagerDuty, and custom endpoints.
  • Automated Response: Configurable remediation workflows triggered by confirmed incidents.
  • API Access: RESTful API for programmatic control and integration with existing security tools.

Implementation Highlight

Here's a conceptual view of how Wardress's risk fusion engine processes multiple detection signals:

Python (Conceptual) 
class RiskFusionEngine:
    def calculate_fused_risk(self, detection_results):
        # Aggregate normalized scores from all layers
        base_risk = sum(r.score * r.weight for r in detection_results)
        
        # Apply minimum-risk floors for high-specificity indicators
        floor_risk = max(
            r.score for r in detection_results 
            if r.is_high_specificity
        )
        
        # Fused score considers both aggregate and floor
        fused = max(base_risk, floor_risk * 0.85)
        
        # Compare against site-specific threshold
        if fused >= self.site.alert_threshold:
            self.trigger_alert(fused, detection_results)
        elif fused >= self.site.review_threshold:
            self.request_ai_review(detection_results)
        
        return fused
