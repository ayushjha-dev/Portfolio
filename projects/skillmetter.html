Skillmetter

A production-ready TryHackMe profile comparison and benchmarking platform.

Overview

Skillmetter is a performance comparison dashboard that compares TryHackMe profiles. It analyses room completions, domain breakdown scores, and badge milestones to generate weighted cybersecurity skill metrics.

Core Capabilities

  • Domain Analysis: Classifies TryHackMe achievements into key domains (Web Exploitation, Cryptography, Reverse Engineering, Network Security, Forensic Analysis).
  • Visual Analytics: Interactive visualizations comparing user rankings, badge gains, and room completion timelines.
  • Intelligent Ranking: Computes weighted scores reflecting room difficulty and completeness rather than just flat point totals.
"Gamified metrics are great, but evaluating true skill progression requires parsing room classifications and calculating weighted metrics over time."

Technical Architecture

  • Frontend Core: React and TypeScript, structured as a clean dashboard utilizing modular graphs.
  • API Integration: Calls TryHackMe's public endpoints using edge proxies to avoid CORS restrictions.
  • Data Engine: Normalizes inconsistent room classifications, sorting them into five core security pillars.

Implementation Highlight

The following TypeScript snippet demonstrates the score weight calculation algorithm:

TypeScript 
interface UserStats {
  points: number;
  completedRooms: Array<{ name: string; type: string; difficulty: string }>;
}

export function computeWeightedScore(stats: UserStats): number {
  const difficultyWeights: Record = {
    easy: 1.0,
    medium: 1.8,
    hard: 3.0,
    insane: 5.0
  };

  let weightedTotal = 0;
  stats.completedRooms.forEach(room => {
    const weight = difficultyWeights[room.difficulty.toLowerCase()] || 1.0;
    weightedTotal += 100 * weight;
  });

  // Combine raw points (reduced impact) with room difficulty weight
  return Math.round((stats.points * 0.1) + (weightedTotal * 0.9));
}
