Obsqura

A cybersecurity blog sharing technical insights, walkthroughs, and OSINT.

Overview

Obsqura serves as my primary notes archive and platform for sharing hands-on tutorials, CTF writeups, OSINT techniques, and practical security insights. It provides clean, technical writeups on web application security issues, active directory environments, and network exploitation.

The Goal & Design

The project focuses on readability, offering a clean layout that makes code snippets, log files, and vulnerability payloads readable for fellow practitioners. Built using Jekyll and static page hosting, it features high performance, searchability, and ease of deployment.

"Sharing knowledge is how we improve defensive and offensive skills alike. Obsqura documents real-world exploitation paths and defense strategies to promote security education."

Technical Details

  • Jekyll & Markdown: Formulates articles using basic markdown formatting, allowing rapid drafting of CTF walk-throughs.
  • Liquid Templates: Manages tags, categories, read-time estimations, and dynamic table of contents without relying on slow JavaScript client processing.
  • SEO & Speed: Compiles into static HTML assets that load instantly and achieve solid performance rankings across search metrics.

Writeup Template Structure

The following snippet demonstrates how Jekyll front-matter metadata tags categories, write-up difficulty, and references to target labs:

Markdown 
---
layout: post
title: "SQL Injection to Remote Code Execution (RCE)"
category: CTF-Writeups
tags: [web-security, sqli, rce, tryhackme]
difficulty: Medium
machine_ip: "10.10.144.22"
---
