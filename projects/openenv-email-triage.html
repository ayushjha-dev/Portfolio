OpenEnv Email Triage

A modern AI email triage platform to benchmark autonomous agents.

Overview

OpenEnv Email Triage is a realistic environment built to benchmark the performance of autonomous AI agents on inbox management. Agents are tasked with analyzing, tagging, prioritizing, and responding to dynamic queues of simulated professional communications.

The Challenge

Standard benchmarks fail to evaluate agents on multi-step workflows where email content triggers action requirements (e.g., meeting scheduling, document requests, spam filtering). This environment evaluates how agents follow long-term instructions, manage context, and handle complex triage tasks.

"Inbox management is a core target for AI assistance, but evaluating reliability requires reproducible test beds. OpenEnv Email Triage fills this gap with deterministic score metrics."

Technical Architecture

The environment uses a wrapper around inbox simulators, offering API sandboxes for agent actions:

  • Inbox Simulator: Generates synthetic email threads featuring varying tones, requirements, and noise levels.
  • Reward Model: Computes precision, recall, and action accuracy (e.g., did the agent schedule the calendar invite correctly? Did it route sensitive documents to the right folder?).
  • Infrastructure: Built with an API schema that integrates with agent libraries like LangChain, AutoGPT, or raw LLM clients.

Implementation Highlight

This Python callback shows how the environment initializes an inbox state and evaluates an agent's categorization choices against baseline answers:

Python 
def evaluate_triage_action(agent_response, ground_truth):
    """
    Evaluates classification labels and priority routing scores.
    """
    score = 0.0
    # Evaluate categorization accuracy
    if agent_response.get("category") == ground_truth.get("category"):
        score += 0.5
        
    # Evaluate priority rating accuracy (1 to 5 scale)
    priority_diff = abs(int(agent_response.get("priority", 3)) - int(ground_truth.get("priority", 3)))
    score += max(0, 0.5 - (priority_diff * 0.1))
    
    return {
        "score": score,
        "perfect_match": score == 1.0,
        "details": f"Diff priority: {priority_diff}"
    }
