ParcelPort

Smart hostel parcel management and delivery coordination system.

Overview

ParcelPort automates the logistics of student hostel parcel deliveries, managing ingress, storage, tracking notifications, and verification.

The Challenge

Manual paper logs for hostel parcels lead to lost packages, delayed student notifications, and unsecured access to storage rooms. I wanted to design a secure, database-backed platform with dedicated role portals.

"Hostel logistics need security and speed. ParcelPort eliminates manual registration and ensures students get real-time collection notifications instantly."

Technical Architecture

The platform relies on role-based authentication and real-time ledger tracking:

  • Role-Based Authorization: Custom authentication middleware serving distinct client views and API permissions for Admin, Student, and Delivery staff.
  • Parcel Lifecycle Log: Tracks each package from initial check-in (courier), verification staging (admin), notifications (system), to final signature pickup (student).
  • Notification Handler: Triggered on data check-in to auto-compile and dispatch email and messaging warnings with collection codes.

Implementation Highlight

This Node.js middleware snippet shows how roles are validated against JSON Web Tokens before letting users edit parcel statuses:

JavaScript 
const authorizeRoles = (...allowedRoles) => {
  return (req, res, next) => {
    // 1. JWT verification assigns user role to req.user
    if (!req.user || !allowedRoles.includes(req.user.role)) {
      return res.status(403).json({ 
        error: "Access denied. Insufficient permissions." 
      });
    }
    // 2. Pass control to next router step
    next();
  };
};
