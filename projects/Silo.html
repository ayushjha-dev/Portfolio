ilo

A zero-knowledge, single-user cloud password manager.

Overview

ilo is a zero-knowledge password manager designed to run fully client-side for vault encryption, using cloud architecture solely to synchronize encrypted blobs. Even under full database compromise, user vault details remain cryptographically unreadable.

Security Model & Key Derivation

By utilizing the browser's Web Crypto API alongside server-side verification salts, ilo executes a multi-layered Argon2id key derivation flow:

  • Encryption Key: Derived via MasterPassword + kdfSalt → (Argon2id) → EncryptionKey. This key is held strictly in browser memory, never sent to the network, and cleared instantly on session locking or tab closure.
  • Auth Verifier: Derived via MasterPassword + authSalt → (Argon2id) → AuthVerifier → (bcrypt) → stored in Database. This separates authentication credentials from the actual decryption material.
"True zero-knowledge ensures that recovery flow bypasses are mathematically impossible. If the master password is lost, the vault is permanently unrecoverable, leaving no backdoor open."

Technical Architecture

The tech stack has been optimized for low-latency browser crypto operations:

  • Frontend: Next.js 16 (App Router), React 19, TypeScript, and Tailwind CSS v4.
  • Crypto Engine: argon2-browser (WASM-based Argon2id) for browser processing, Web Crypto SubtleCrypto for AES-256-GCM, and Speakeasy (TOTP) for 2FA.
  • Database: PostgreSQL managed instance connected via Prisma ORM.

Implementation Highlight

This TypeScript snippet displays how the client derives the local AES key and performs vault encryption using authenticated additional data:

TypeScript 
export async function encryptVault(vaultJson: string, rawKey: Uint8Array): Promise<{ ciphertext: ArrayBuffer; iv: Uint8Array }> {
    const cryptoKey = await window.crypto.subtle.importKey(
        "raw",
        rawKey,
        { name: "AES-GCM" },
        false,
        ["encrypt"]
    );

    const iv = window.crypto.getRandomValues(new Uint8Array(12));
    const encoder = new TextEncoder();
    const encodedData = encoder.encode(vaultJson);
    
    // Bind the ciphertext to prevent context replay
    const additionalData = encoder.encode("silo-vault-v1");

    const ciphertext = await window.crypto.subtle.encrypt(
        {
            name: "AES-GCM",
            iv: iv,
            additionalData: additionalData
        },
        cryptoKey,
        encodedData
    );

    return { ciphertext, iv };
}
