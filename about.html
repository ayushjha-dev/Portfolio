About Me

Bridging the gap between secure design and clean development.

My name is Ayush Kumar Jha, and I am currently pursuing a B.Tech in Cyber Security (IBM) at Lamrin Tech Skill University.

I build systems that work efficiently and defend themselves. As a B.Tech Cyber Security (IBM) student at Lamrin Tech Skill University, I believe that building secure software is not an afterthought, but a core architectural requirement.

My background combines full-stack web application development with hands-on research in application security, penetration testing, cryptographical mechanics, and SOC operations (SIEM/SOAR). I enjoy building things (using TypeScript and Python) and testing their boundaries by modeling threat vectors and analyzing software configurations.

Outside of university assignments, you will find me practicing penetration testing labs on HackTheBox, reviewing CVE databases, studying malware analysis blogs, or developing helper scripts for automated security audits.
