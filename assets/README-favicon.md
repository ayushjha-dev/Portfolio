# Favicon Generation

## Current Setup
- **favicon.svg**: Main favicon (32x32, scalable)
- Modern browsers will use the SVG version automatically

## To Generate PNG Version (Optional)
If you need a PNG fallback for older browsers:

1. Open `favicon-generator.html` in your browser
2. Click "Download as PNG" button
3. Save as `favicon.png` in the `assets/` folder

Or use any SVG to PNG converter online:
- Upload `favicon.svg`
- Export at 32x32 pixels
- Save as `favicon.png`

- Background: `#1a1a19` (dark charcoal)
- Inner background: `#121211` (darker charcoal)
- Accent (A.J. monogram): `#d35e35` (terracotta/rust)
